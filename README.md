Entry for the [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on make.fun.

The program writes exactly one emoji for a dream vacation — a single Unicode code point — to `/output/entry.txt`. Nothing else is written; the emoji stands alone, with no trailing newline.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript is run as-is). The emoji is written to `/output/entry.txt` with no trailing newline.
